# Changelog

All notable changes to Power Outage Tracker will be documented in this file.

## 0.3.0

- Track grid power using one or two smart-plug availability sources.
- Preserve active and most recently completed power and outage periods across
  Home Assistant restarts.
- Suppress startup and transient connectivity false positives with configurable
  confirmation delays.
- Allow source entities and delays to be changed after setup.
- Provide native and localized dashboard-oriented duration and timestamp
  sensors in English and Ukrainian.
- Include integration and entity icons for light and dark Home Assistant themes.
